# PractikProgaInvet
## Описание:
Проект создан во время практики на предприятии кск ит.
В проекте осуществляется поиск актива по его шрихкоду или вводу кода в поисковую строку, у пользователя есть возможность редактировать информацию о активах(состояние) и перемещать их по складу(с сохранением истории)
